# Ассеты темы Craftunity

Файлы создаются скриптом `tools/generate_assets.py` (палитра взята из `ui/styles.css`, иконка — `icon.png`).

| Файл | Назначение |
|---|---|
| `background.png` | фон главного меню, 1920×1080, тёмный с оранжевым свечением и встроенными панелями |
| `logo.png` | знак Craftunity + надпись CRAFTUNITY / LAUNCHER |
| `btn_normal.png` | кнопка в обычном состоянии |
| `btn_hover.png` | кнопка под курсором |
| `btn_focus.png` | кнопка для ванильных кнопок главного меню (замена текстуры виджета) |
| `panel.png` | полупрозрачная панель (дев-слайс) |
| `divider.png` | тонкая линия акцента |
| `sidebar.png` | левая колонка навигации (дев-слайс) |

Не коммитьте сгенерированные PNG — их пересоздаёт скрипт.
