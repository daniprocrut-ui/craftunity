Как играть

  1. Скачайте exe и сохраните его в любое место.
  2. Запустите файл. Windows может показать запрос SmartScreen — подтвердите запуск.
  3. В лаунчере войдите по нику или через аккаунт ely.by.
  4. Нажмите кнопку «Играть» и ждите загрузки.
