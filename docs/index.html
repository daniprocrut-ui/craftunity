Windows не даёт запустить файл?

SmartScreen предупреждает о файлах без цифровой репутации — это нормально для маленьких проектов. Вот как пройти окно.

Окно «Система Windows защитила ваш компьютер»

Нажмите «Подробнее», затем появившуюся кнопку «Выполнить в любом случае».

  1. Нажмите ссылку «Подробнее» слева, под текстом про неопознанное приложение.
  2. Внизу слева появится кнопка «Выполнить в любом случае» — нажмите её.
  3. Если кнопки нет: закройте окно, откройте свойства exe и отметьте «Разблокировать», затем запустите снова.

Окно «Не удалось найти приложение» / файл не запускается

  1. Нажмите Подробнее в окне.
  2. Выберите в списке Smartscreen.exe и нажмите Удалить.
  3. Повторите запуск лаунчера.

Если файл просто скачался и не открывается

  1. Откройте папку с файлом и нажмите правой кнопкой на exe.
  2. В свойствах на вкладке «Общие» отметьте Разблокировать и нажмите «ОК».
  3. Запустите файл снова.

Как убрать предупреждение навсегда

Предупреждение SmartScreen зависит от репутации файла в Microsoft. Она растёт по мере скачиваний, а также снимается при подписи кода.

Как играть

  1. Скачайте exe и сохраните его в любое место.
  2. Запустите файл. Windows при первом запуске покажет окно SmartScreen — как пройти его, см. выше.
  3. В лаунчере войдите по нику или через аккаунт ely.by.
  4. Нажмите кнопку «Играть» и ждите загрузки.
